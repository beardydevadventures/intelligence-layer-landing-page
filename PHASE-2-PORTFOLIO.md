# Phase 2 B2B portfolio

Digital Twin Operations is an independent concept / prototype, using real Blender and browser captures. The standalone application is served at /demos/digital-twin-operations/; it is not embedded on the homepage. The 24-second MP4 is served by the existing Cloudflare website at /media/digital-twin-operations/operations-demo-24s.mp4. Sanity stores the project images, alt text, captions and video/poster metadata.

The retired case studies are preserved as Sanity drafts and removed from published content, homepage selection and VR-service references. The offline baseline contains no retired projects. Team publication is disabled in CMS and missing-content defaults do not supply founder names.

The application bundles Three.js 0.180.0 and loads the original Blender GLB. Telemetry and recommendations are simulated; no connected AI, live IoT or WebXR is claimed. Inspection tasks are temporary browser-session records.

No schema changes are required. Future editorial improvements: separate hero media, demonstrator type, structured capabilities/outcomes and visible video captions. Valve Tutorial needs a new case study with approved attribution, verified capability/context copy and real media before publication.

Verification includes npm test, npm run build, npm run validate:site and desktop/mobile browser checks for the homepage, case study, video playback, gallery alt text, standalone demo selection and retired 404 routes. Standalone demo HTML is outside the sales-page template validator and has separate browser verification.
